# 2026-11-05 CornerWeather

## 依赖导入（《第一行代码》第15章 天气 App）

项目模板是新版（Kotlin DSL + `gradle/libs.versions.toml` 版本目录 + Compose），书里的 Groovy 老写法不适用，全部改为 version catalog 形式。

版本取舍：
- `androidx.recyclerview` 1.0.0 → **1.4.0**
- `androidx.swiperefreshlayout` 1.0.0 → **1.1.0**
- `com.google.android.material` 1.1.0 → **1.12.0**
- `retrofit` / `converter-gson` 2.6.1 → **2.11.0**
- `kotlinx-coroutines-android` 1.1.1 → **1.9.0**（与 Kotlin 2.0.21 匹配；core 由 android 传递引入）
- `lifecycle-extensions:2.2.0` **已废弃**，替换为 `lifecycle-viewmodel-ktx` + `lifecycle-livedata-ktx`（复用 lifecycleRuntimeKtx = 2.10.0）

## 两个必做配套改动

1. `AndroidManifest.xml` 加 `<uses-permission android:name="android.permission.INTERNET" />`，否则 Retrofit 请求抛 SecurityException。
2. `res/values/themes.xml` 父主题 `android:Theme.Material.Light.NoActionBar` → `Theme.Material3.DayNight.NoActionBar`，否则 MaterialCardView / MaterialButton 运行时报「theme must be Theme.MaterialComponents」。

## 环境注意

- 本机 `~/.gradle/gradle.properties` 配了 Clash 代理 `127.0.0.1:7897`，AI 沙箱内连不上该代理，验证构建时用 `-I /tmp/noproxy.gradle` 清掉 proxy 系统属性才跑通。用户自己在 Android Studio 里构建保持代理开启即可。
- JDK 需用 `JAVA_HOME=/Applications/Android Studio.app/Contents/jbr/Contents/Home`（系统无默认 JDK）。

## 验证结果

`./gradlew :app:assembleDebug` BUILD SUCCESSFUL；APK 内已确认打包 recyclerview / swiperefreshlayout / material / retrofit / coroutines 类，`aapt2 dump permissions` 显示 INTERNET 权限已生效。
