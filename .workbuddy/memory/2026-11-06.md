### 关键坑
- **lifecycle 2.6+ 移除 `Transformations` 类**，改为扩展函数：`liveData.switchMap { }` / `.map { }`，需 `import androidx.lifecycle.switchMap`。
- `?android:attr/textColor` 在主题里无值，inflate 抛 `UnsupportedOperationException: Failed to resolve attribute at index 5`，只能用 `textColorPrimary` / `textColorSecondary`。
- `LiveData` 惰性：没有 observe 时 `setValue` 不触发 switchMap，接口根本不会发。这是"输入有日志但无请求"的常见原因。

### 网络排错（本次核心）
- 模拟器：`ip addr` 只有 lo/dummy、`ip route` 空、`ping 8.8.8.8` → Network is unreachable，**模拟器彻底没网**，任何请求必失败。
- 真机：装 VPN（`io.tomato.cloud` 番茄加速器，TUN 全隧道）时，其 LinkProperties 声明了 `HttpProxy: 127.35.135.119:46393`，OkHttp 默认读系统代理 → 发 `CONNECT api.caiyunapp.com:443` → 代理回 `IOException: Unexpected response code for CONNECT: 502`。
- 结论：`CONNECT 502` 是手机代理/VPN 造成的，与 Retrofit 代码无关。解法优先级：关 VPN > 把域名/应用加入 VPN 豁免 > 代码里 `OkHttpClient.Builder().proxy(Proxy.NO_PROXY)` 并 `.client(client)` 挂到 Retrofit。
